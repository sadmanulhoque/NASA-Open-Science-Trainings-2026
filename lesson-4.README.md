# Components of Open Science

## Overview
Open science means sharing your research so others can use it, check it, and build on it.  
The main things you can share are: **data**, **code**, **results**, and **papers**.

## The Open Science Pyramid
Think of open science like a pyramid:

- **Top**: Research papers (summaries of the work)
- **Base**: Data, code/software, and results

Sharing all of these makes science more trustworthy and useful.

## Open Data
**Open data** is data that anyone can freely use, share, and build upon (with proper credit).

### Good open data should:
- Have clear descriptions (metadata)
- Include a license and citation info
- Be easy to find and download
- Show how it was created and any changes made

### Types of Data
- **Primary data**: Collected by you (surveys, measurements, experiments)
- **Secondary data**: Data someone else already collected
- **Metadata**: Information that describes the data

### Benefits of Sharing Data
- Helps other scientists check and reuse your work
- Supports faster discoveries and better decisions
- Helps with public safety (example: tsunami warning data)
- Allows more people to contribute ideas

### When to Share Data
- **Early**: Soon after collection (best for impact)
- **At publication**: When the paper is published
- **At end of project**: Required by many funders

### Use Open File Formats
Prefer formats that anyone can open without special software:
- CSV, TXT, JSON, NetCDF, GeoTIFF, etc.

Avoid closed formats like .psd or .dwg when possible.

## Open Code and Software
Scientists often write code to analyze data.  
**Open-source software** means the code is free to use, change, and share.

### Why open code is useful
- Others can reproduce your results
- People can improve the code together
- Saves time (no need to start from scratch)

### Before using open software, check:
- Does it do what you need?
- Is it easy to use?
- Is it safe?
- What does the license allow?

## Open Results
Results are the outputs of research. They include:
- Papers
- Presentations
- Notebooks
- Blog posts
- Videos
- Software and data

Share results in many ways, not only in traditional papers. This increases visibility and invites feedback.

## Making Results Reproducible
Reproducibility means others can get the same results using the same data, code, and methods.

Helpful tools:
- Jupyter Notebooks
- R Markdown
- Quarto
- Binder

## Key Takeaway
Share as much as you can, as early as you can, and as openly as possible.  
This makes science better for everyone.
